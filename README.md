# C Calculator

A beginner C calculator built as part of my journey learning C programming through hands-on projects.

## Overview

This project is a simple command-line calculator that accepts user input, performs arithmetic operations, and displays the result.

The goal of the project was to strengthen my understanding of C fundamentals by building something functional from scratch.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- User input
- Basic input handling
- Conditional logic
- Command-line interface

## Concepts Practiced

- Variables
- Data types
- `printf()`
- `scanf()`
- Arithmetic operators
- Conditional statements
- Basic program structure
- Compiling and running C programs with GCC

## Technologies

- C
- GCC
- Linux / WSL
- Git
- GitHub
